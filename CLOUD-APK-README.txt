Jee OS 2.5.0 — Continuous 6-Hour PCM Plan

This project keeps the existing GitHub Actions workflow for building a debug Android APK. The schedule is Monday through Saturday in one continuous 6-hour block: 2 hours each for Physics, Chemistry and Maths. Sundays remain test/rest days.

The APK is not included in this ZIP. Push the project to GitHub and run the existing Build Android Debug APK workflow to build it.
