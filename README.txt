Jee OS 2.5.0 — Continuous 6-Hour PCM Plan

- Monday through Saturday: one continuous 6-hour study block.
- Physics: 2 hours; Chemistry: 2 hours; Maths: 2 hours.
- Each subject follows its own chapter order. Whole videos are scheduled using playlist-average duration estimates at 1.5x playback. Videos that do not fit carry forward for that subject.
- Sundays remain protected for the existing test/rest system.
- Curriculum: Physics 43 chapters / 481 listed lectures; Chemistry 49 / 868; Maths 37 / 1,376. Total 129 chapters / 2,725 lectures.
- The project retains revision cycles, tests, calendar, local progress, optional Supabase sync, playlist links and the Android build workflow.

Windows: install Node.js 22+, extract the ZIP, and run start.bat. Do not open index.html directly.
